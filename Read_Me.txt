Steps to run the code:

Create a virtual environment
python -m venv venv

Activate virtual environment
.\venv\Scripts\Activate.ps1

Install dependecies
pip install -r requirements.txt

Run the code
python logistic_regression_intrusion.py

N.B. Please note that, it takes a lot of time to import the dataset using the ucmli library. So the code might seem stuck when executing for the very first time.
